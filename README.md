# Carrier Allays  
carrier pigeons, but they're allays.

[Demo](https://github.com/user-attachments/assets/56904b9f-f3a2-42f5-aab9-de937a9e8e2d)

name an allay after someone whos online (with a name tag), hand it a little package, and off it goes to deliver it. when the job is done it flies back home to you. because it misses you. :3

how to use:

    name an allay after a player
    give it a thing
    it delivers the thing

and if your friend lives really really far away, the allay does a cute little fly-off and then quietly teleports most of the way there. nobody has to see that part.

Two versions of how it works:

**Vanilla mode**
This is the default way the plugin works. You find an allay naturally and you can then name it after the player and send off the package.

**Matcha Flavoured Mode**
Requires [Minecraft Matcha Flavoured](https://modrinth.com/datapack/matcha-flavoured)

You craft the carrier allay with a book and quill and an amalgamated pith. 

<img width="595" height="475" alt="adssadf" src="https://github.com/user-attachments/assets/0ae00d51-39ee-42fd-b9b7-b5d575085a35" />


After which you can spawn in the allay, rename it to a player's name and send it off. This mode can be setup in the plugin config and also requires the acompanying texture pack. (Or you can make your own texture)

See the github to download the included texturepack or to learn how to implement your own: [Releases page](https://github.com/xoxoxizzy/Carrier-Allays/releases)
